# DESIGN.md 更新紀錄

記錄 [`DESIGN.md`](./DESIGN.md) 每個版本的變動，最新版本在最上面。

**寫法**

- 版本號規則見 DESIGN.md 開頭〈版本規則〉：主版本需要改程式、次版本畫面會變、修訂號不影響畫面
- 每一版第一行寫「開發影響」，讓開發者一眼判斷要不要動
- 變動依類型分組：**新增／變更／棄用／移除／修正**，沒有的類型省略
- 每一條寫出章節編號，改到 token 時寫出 token 名稱
- 主版本與次版本更新後，由 UI/UX 負責人通知開發者，並附上該版紀錄

**範本**

```markdown
## 1.1.0（2026/09/20）

開發影響：不需改程式，畫面會變

### 新增
- §8.x ……
### 變更
- §3.2 `type/body` 行高 1.6 → 1.5
### 棄用
- §8.3 `Chip/Suggest` 改用 `Chip/Soft`；1.x 期間保留舊名，2.0.0 移除
### 修正
- §9 範例錯字
```
