## 名詞

- **步數**：用來算點數的步數。搭過車之後是實際步數 × 1.5。
- **門檻**：2,000、4,000、6,000，每個門檻 1 點，一天最多 3 點。
- **可以領**：步數已經到門檻、還沒領取的點數。
- **N**：文案裡的 N 一律換成實際數字，步數加千分位（例：1,000）。

## S1 拿掉三列

移除 2,000／4,000／6,000 三列（`.yo-milestone`）和每列右邊的狀態標籤（`.yo-mile-state`）。三列原本的資訊改由 S2 的圓和 S3 的一句話表達。

「原始 N 步・有效 N 步」「最多 3 點／日」那一行也拿掉。原因：

- **原始與有效步數**：沒搭車時這兩個數字一樣，並排只是同一個數字寫兩次。改成「兩個數字不一樣的時候才顯示第二個」——沒搭車時畫面上只有地圖上那一個步數；搭車之後，大數字下面才多一行「搭了 yoxi，步數變 1.5 倍・實際走了 N 步」（見 S8）。資訊沒有少，只是換到有差別的時候才出現，而且不用「原始」「有效」這兩個系統用語。
- **最多 3 點／日**：卡片右上的「N / 3 點」和進度條上的三顆 P 已經表達一天最多 3 點。

如果「有效步數」除了搭車 × 1.5 之外還有別的計算（例如過濾異常步數），這個做法會蓋不到，請先回報再動。

## S2 進度條

一條軌道，上面四顆圓，圓心壓在軌道上。腳步圖示拿掉。

**軌道**

- 高 5，分三段，每段代表 2,000 步，段與段之間留 3 的空隙
- 已經走到的部分填墨藍 `#0B1F38`，還沒走到的部分是 `#C3CBDC`
- 填色跟著步數連續變化（例：5,000 步時，第三段填一半）
- 整條都是墨藍，走滿 6,000 也不變色

**四顆圓**：直徑都是 24，位置在 0、2,000、4,000、6,000

| 位置 | 狀態 | 樣子 |
|---|---|---|
| 0（起點） | 固定 | 白底、1.5 的墨藍框，裡面是鞋子圖示（跟底部分頁「步數」同一個） |
| 門檻 | 已領取 | 墨藍底，白色勾勾 |
| 門檻 | 可以領 | 墨藍底，白色粗體「P」；右上角疊一顆直徑 8 的紅點 `#F14A42`，紅點有 1.5 的白邊 |
| 門檻 | 還沒到 | 灰底 `#C3CBDC`，白色粗體「P」 |

**圓下面的數字**：0、2,000、4,000、6,000，12px、`#778AA4`，對齊各自的圓。

卡片右上的計數維持「已領取的點數 / 3 點」（例：1 / 3 點）。

## S3 一句話

放在進度條下面。大字 18px 墨藍，其中的點數（「N 點」）用紅色粗體 `#EF392A`；小字 13px `#778AA4`。

| 狀態 | 大字 | 小字 |
|---|---|---|
| 沒有可以領的，還沒走滿 6,000 | 再走 N 步，就可以領 1 點 | 不顯示 |
| 有可以領的，還沒走滿 6,000 | 有 N 點可以領 | 再走 N 步，就可以再領 1 點 |
| 有可以領的，已經走滿 6,000 | 有 N 點可以領 | 今天的目標達成了 |
| 3 點都領完 | 今天的 3 點都領到了 | 不顯示 |

「再走 N 步」的 N = 下一個還沒到的門檻 − 目前的步數。

## S4 領取按鈕

- 緊接在 S3 那句話下面，滿寬、高 54、墨藍底白字
- 文字：「領取 N 點」，N 是全部可以領的點數；按一次全部領完
- **沒有可以領的點數時，整顆按鈕不顯示**（不要留灰色的停用按鈕）
- 按鈕不加光暈（紅色光暈的移除已另外講過）

領取之後：對應的圓變成勾勾、右上計數加上去、S3 的句子跟著換。

## S5 搭一趟 yoxi

取代現在的「乘車加成：尚未搭乘」那一行。**位置在領取按鈕下面**，上方一條 1px 分隔線 `#DFE4ED`。

一列三欄：

| 欄 | 內容 |
|---|---|
| 左 | 52 × 52 的灰底格子 `#F2F6F9`，上面是車子圖示，下面兩行粗體小字「步數」「1.5 倍」 |
| 中 | 標題「搭一趟 yoxi」（18px 粗體）；下面一行說明（13px `#778AA4`） |
| 右 | 小按鈕或狀態 |

說明與右欄依狀態換：

| 狀態 | 說明 | 右欄 |
|---|---|---|
| 還沒搭，而且今天還沒走滿 6,000、實際步數 ≥ 4,000 | 0 / 1・搭一趟，今天的目標直接達成 | 外框小按鈕「模擬一趟」 |
| 還沒搭，其他情況 | 0 / 1・今天的步數變 1.5 倍 | 外框小按鈕「模擬一趟」 |
| 已經搭過 | 1 / 1・今天的步數變 1.5 倍 | 灰字加勾「已完成」，不能按 |

外框小按鈕：高 28、膠囊形、白底、1px 墨藍框、墨藍粗體 13px。不要用實心墨藍，全卡只有 S4 那顆是實心。

「今天的目標直接達成」只在搭了真的會走滿 6,000 時才寫（實際步數 × 1.5 ≥ 6,000，也就是實際步數 ≥ 4,000）。

## S6 慶祝彈窗

按下「模擬一趟」、搭車成功後跳出。

**外觀**

- 遮罩：`rgba(11, 31, 56, 0.85)`，蓋住整個畫面
- 面板：置中、寬 296、白底、圓角 24、內距上 28 左右 24 下 24、內容置中
- **按遮罩不會關閉**，只能按面板裡的按鈕

**內容，由上到下**

| 順序 | 內容 | 樣式 |
|---|---|---|
| 1 | 車子圖示 | 83 × 83 的淡杏色方塊 `#F3EBE4`、圓角 10，裡面是紅色車子 |
| 2 | 標語「Nice Ride!」 | Montserrat 斜體 900、28px、墨藍 |
| 3 | 今天的步數變 1.5 倍 | 18px 墨藍 |
| 4 | 「5,000 → 7,500 步」 | 原本的步數 18px 粗體 `#778AA4`；箭頭；新的步數 28px 粗體紅色 `#EF392A`；「步」18px 粗體墨藍 |
| 5 | 一行小字 | 13px `#3C4C60`，內容見下表 |
| 6 | 按鈕 | 同 S4 的樣式，滿寬，文字見下 |

第 4 行的兩個數字：左邊是實際步數，右邊是 × 1.5 之後的步數。

**按鈕**：只看搭完之後有沒有點數可以領。

| 情況 | 文字 | 按下去 |
|---|---|---|
| 有可以領的點數 | 領取 N 點（N 是全部可以領的） | 領取全部，並關閉彈窗 |
| 沒有可以領的 | 知道了 | 只關閉彈窗 |

**小字**：看這一趟帶來什麼。

| 情況 | 小字 | 對應圖 |
|---|---|---|
| 這一趟多出新的可以領的點數 | 多了 N 點可以領（N 是這一趟多出來的） | 圖二左邊 |
| 沒有多出新的點，還沒走滿 6,000 | 再走 N 步，就可以領 1 點 | 沒有畫 |
| 沒有多出新的點，已經走滿 6,000，還有沒領的 | 今天的目標達成了 | 沒有畫 |
| 今天 3 點都已經領完 | 今天的 3 點都領到了 | 圖二右邊 |

由上往下判斷，符合就用那一句。

**例子**

| 搭車前 | 搭車後 | 小字 | 按鈕 |
|---|---|---|---|
| 5,000 步，已領 1 點，1 點可以領 | 7,500 步，多 1 點可以領 | 多了 1 點可以領 | 領取 2 點 |
| 1,000 步，沒有可以領的 | 1,500 步 | 再走 500 步，就可以領 1 點 | 知道了 |

## S7 彈窗的動畫

只播一次，不循環，全長約 1.5 秒。寫法在 `32-demo-ride-feedback.html`（class 名稱 `z-` 開頭）。彈窗彈出的部分可以沿用寶箱現有的動畫。

| 開始時間 | 長度 | 動作 |
|---|---|---|
| 0 | 0.25 秒 | 面板從 0.9 倍放大到 1 倍，同時淡入 |
| 0.15 秒 | 0.35 秒 | 車子方塊從 0.6 倍彈到 1 倍，帶一點回彈 |
| 0.25 秒起，每片再錯開 0～0.12 秒 | 0.6 秒 | 16 片彩色紙片從車子方塊的中心往兩旁飛到定位，邊飛邊轉，停住後留在原地 |
| 0.3 秒 | 0.25 秒 | 標語淡入 |
| 0.4 秒 | 0.25 秒 | 第 3、4 行淡入 |
| 0.4 秒 | 0.9 秒 | 新的步數從原本的數字滾到新的數字，先快後慢 |
| 1.3 秒 | 0.25 秒 | 小字和按鈕淡入 |

紙片：

- 共 16 片，只放在面板上半部、車子方塊的左右兩側，不蓋到文字
- 三種形狀：10 × 5 的長方形、直徑 7 的圓、4 × 12 的細條
- 五種顏色：`#EF392A`、`#0B1F38`、`#EEE1D5`、`#FFF571`、`#0C4C80`
- 位置、顏色、角度在 HTML 裡是寫死的，可以照抄

使用者開了系統的「減少動態效果」（`prefers-reduced-motion: reduce`）時，不播動畫，直接顯示播完的畫面。

## S8 彈窗背後的畫面

彈窗跳出的同時，步數頁本身也要更新，彈窗關掉後看到的就是新的狀態：

- 地圖上的大數字換成 × 1.5 之後的步數
- 大數字下面多一行：「搭了 yoxi，步數變 1.5 倍・實際走了 N 步」（N 是實際步數）。這一行之後一直留著
- 進度條、四顆圓、S3 的句子、S4 的按鈕，照新的步數重算
- S5 那一列換成「已經搭過」的狀態
