# FSD-PA-10　Yoika 對話（公開測試版，Gemini）

> 2026-10-13 產品負責人決定：只在公開測試版加入 Yoika 對話，背後由 Gemini 回答；只用平台內資料；初賽截止（10/14 13:00）前上線。內部展示版維持 PRD D01（首版不開發 AI）。

## 責任

訪客在公開測試版開啟「和 Yoika 聊聊」，用文字詢問步行與移動相關問題。Yoika 透過 Gemini 回答，數字一律由本機工具從訪客自己的體驗資料取得。

## 範圍

| 可回答 | 婉拒 |
|---|---|
| 今天／昨天的步數、可領點數、離下一點差多少 | 醫療診斷、投資、政治、寫作業、寫程式、與移動無關的閒聊 |
| 七日全勤、團隊 30 萬步、寶箱、推薦規則 | 真實地點推薦（第一版沒有地點資料） |
| 模擬天氣與出門建議 | 代為叫車、發券、承諾優惠 |
| 走路還是搭 yoxi（時間估算；車資以叫車頁為準） | |

## 輸入／輸出

- 入口（2026-10-13 產品負責人）：頂部列中央浮動的魷魚 logo 即按鈕，下方小對話框寫「和 Yoika 聊聊」，第一次開過聊天後隱藏（記在訪客體驗資料，重新開始體驗會再出現）；選單與步數頁不另設入口。
- 輸入：訪客文字，最多 100 字；或建議問題按鈕。
- 工具（本機函式，只讀，不寫入）：
  - `get_today_status(day)`：原始步數、有效步數、是否搭過車、已解鎖／已領／可領點數、離下一點的步數。
  - `get_team_status()`：是否有隊伍、人數、本週全隊步數、目標 300,000。
  - `get_weather()`：模擬天氣（與地圖天氣同一來源）。
  - `compare_walk_or_ride(distanceKm)`：步行分鐘（時速 4.8 公里）與搭車分鐘（等車中位數 5.9 分鐘＋車行時速 24 公里），標示為估算；車資不提供。
  - `get_rules()`：平台規則文字（與遊玩指南同源）。
- 輸出：模型回覆須以 `[OK]` 或 `[NO]` 開頭；程式只在 `[OK]` 且通過檢查時顯示內容，其餘顯示固定婉拒句。

## 資料擁有者與權限

- 體驗資料仍只在訪客瀏覽器（`src/local`）；Yoika 只讀。
- 送往 Gemini 的內容：訪客輸入、工具回傳的數字與規則文字。不送名稱以外的身分資料，不送位置座標。
- 呼叫走 Firebase AI Logic（Gemini Developer API，免費方案，不綁卡；專案開啟重送攻擊保護，每次請求用一次性 App Check 權杖）＋ App Check（reCAPTCHA Enterprise，即 Google Cloud Fraud Defense；2026-10 起 Console 不再接受傳統 v3）。設定值為公開的 Web App 設定，放在 `.env.public`。

## 錯誤與保護

| 情況 | 處理 |
|---|---|
| 未設定（缺 Firebase 設定） | 入口顯示「Yoika 對話準備中」，不呼叫任何服務 |
| 逾時（25 秒；查資料會與模型來回 2–3 次）、額度用完、網路錯誤 | 顯示「Yoika 現在有點忙，請稍後再試」；不自動重送 |
| 回覆缺標籤、`[NO]`、含網址、超過 400 字 | 顯示固定婉拒句或截斷 |
| 每次對話上限 10 則、每台瀏覽器每天 30 則、兩次送出間隔 3 秒 | 只是使用體驗上的限制；真正的上限是免費方案額度與 App Check |
| 工具呼叫輪數超過 3 | 停止並顯示忙碌訊息 |

## 依賴

`firebase/ai`、`firebase/app-check`、`@firebase/app`（公開版的 `firebase/app` 別名指向本機替身，Yoika 直接用真的 `@firebase/app` 另建一個 app）。

## 產品負責人需在 Console 完成（Claude 不操作）

1. `yoi-public-demo` 專案註冊 Web App，把設定值給開發（非機密）。
2. AI Logic → 開始使用 → 選 Gemini Developer API（不綁卡）。
3. App Check：在 Google Cloud「Fraud Defense」建立 reCAPTCHA Enterprise 網頁金鑰（分數型、不勾核取方塊；網域 `yoi-public-demo.web.app`、`yoi-public-demo.firebaseapp.com`，不加 localhost，本機改用偵錯權杖），在 App Check 註冊；確認能用後對 AI Logic 開啟強制執行。
4. （建議）Google Cloud 主控台把 API 金鑰限制為上述網域。

## 2026-10-14 修訂（產品負責人選 A＋B）

- 起因：Gemini 免費方案尖峰排隊，單次回應 36–90 秒以上，超過 25 秒逾時，訪客只看到「有點忙」。App Check 正常。
- **A 每題只呼叫一次**：每則問題前附［平台資料］（今天、昨天、團隊、模擬天氣），工具只保留 `compare_walk_or_ride`；其餘查詢不再來回。
- **B 系統備援答案**：逾時或失敗時，四個建議問題與「N 公里走路還是搭車」改由系統用同一份資料回答，灰底並標「系統資料（非 AI 生成）」，前綴「Gemini 目前使用量很高，先給您系統查到的資料：」；其他問題顯示「Gemini 目前使用量很高，請稍後再試，或先點上方的建議問題。」
- 等待超過 8 秒，提示改為「Gemini 比較忙，請再等一下…」。

## 已知限制

- 免費方案額度由所有訪客共用；用完時只會顯示忙碌訊息。
- 免費方案的內容可能被 Google 用於改善產品；關於頁已註明送出內容範圍。
- 前端限額可被清除瀏覽器資料繞過。
