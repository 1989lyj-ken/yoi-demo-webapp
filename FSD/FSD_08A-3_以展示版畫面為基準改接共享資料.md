# FSD-08A-3 以展示版畫面為基準改接共享資料（08A-1 修正）

**狀態**：契約第 3 版（2026-10-04）。D1–D11、Q1–Q4 已裁決；Architect 附條件通過，阻擋 B1–B3 與條件 C1–C12 已併入（見文末）。N1、N2、B1 已裁決（第三批）；Architect 短版確認附條件通過，補充條件已併入 B1 段與正文。**審查完成（Security 通過、QA 短版確認通過），待產品負責人部署前端並人工驗收。** **不改 Rules、不重設場次**；上線只需部署前端。

## 緣由

08A-1 的目標是「以展示版（`src/showcase/app.ts`）的畫面為基準，把共享資料搬進來」。實作卻選了「現有共享面板原封不動掛進分頁、只用 CSS 改外觀」（08A-1 §1），結果四個分頁裡仍是工程長頁面的條列版型，展示版的週曆、步數點數卡、里程碑卡、隊伍橫幅、隊員頭像卡、乘車券卡、寶箱卡都消失了。產品負責人於發布後指出做反了（2026-10-04）。

本積木改回正確方向：**畫面以展示版為準，資料與規則全部沿用共享端**。

## 不變（硬性條件）

- **不改**任何服務、狀態純函式、Rules（`firestore.rules` 仍為 `70acb267…`）、Firestore 讀寫路徑與訂閱次數。

## 做法

- **改的是畫面標記與樣式**：重寫 `src/ui/views.ts` 中外殼四個分頁用到的區塊與內層 view（`dailyPanelView`、`milestoneRowsView`、`perfectWeekView`、`couponsView`、`rewardsView`、`teamView`／`teamEmptyView`、`referralView`、`mapHeroView`、`inviteCardView`），改用展示版的 `yo-*` 元件結構與 token 樣式。
- **元素 ID 與 `data-*` 掛勾維持不變**，面板控制器（`main.ts` 的每日面板、`team-panel.ts`、`perfect-week-panel.ts`、`rewards-panel.ts`、`referral-panel.ts`）只做必要的小幅調整（例：週曆日期點選、團隊橫幅複製按鈕、里程碑新文字）。
- **診斷畫面**：外層長頁面版型保留；內層元件與外殼共用，因此外觀會一起變成新樣式（僅管理者可見，可接受）。
- `src/showcase/app.ts` 仍保留不刪；樣式類別可沿用，但不再引用其本機狀態。
